# 火災爆炸高風險事業單位職災與違規紀錄查詢系統

網站：https://fefe9487.github.io/fire-explosion-risk-site/

查詢清冊場所的近五年裁罰與職災相關處分，並呈現近三年統計。
裁罰排行分全臺事業單位及清冊場所；設施規則與高壓氣體勞工安全規則各自統計、各取前十條。
統計條件、資料來源與期間請見網站「篩選方式與資料概況」。
火災爆炸相關裁罰依公告引用的法規及條號，對照網站列出的相關條文判斷；說明頁提供完整清單與法規連結。職安法第6條不因敘述出現「火災」或「爆炸」就標紅，確認是防爆、可燃性氣體或粉塵、動火、靜電、發火源，或已發生火災爆炸，才標紅並計入。名稱就是公司本身、後面沒有廠別的那一筆，收下同統編還沒分到各廠的紀錄。名稱後面有廠別的，只計能對到該廠的。仍然對不到的，先不放上公開查詢。

本倉庫只存放公開網站及公開資料。原始清冊、後臺及內部核對資料存於私有倉庫。
官方資料截止查詢日為 2026-10-06；來源實際最新日期另在網站標示。
未查得紀錄不代表沒有事故或違規。

`demo.html` 是可離線開啟的整合版本。GitHub Pages 從 main 分支根目錄發布。
